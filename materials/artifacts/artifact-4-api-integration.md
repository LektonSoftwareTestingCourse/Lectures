> **Проверка**: CI-автопроверка + LLM-проверка (`skill-4`, бонус)

## Что сдаёте

REST-тесты (REST-assured) + интеграционные тесты с контейнеризованной БД/очередями.

## Требования

- Покрыть все endpoint'ы целевых сервисов (позитивные + негативные сценарии).
- Проверить все decline-коды (responseCode + declineReason).
- Интеграционные тесты — с поднятием реальной PostgreSQL в контейнере.
- Проверить цепочку сервисов (сквозной проход транзакции).

## Куда класть

```
services/{service}/src/test/java/...
```

## Как сдавать

Ветка + Issue с label `practice-4`. CI проверяет сборку/тесты; LLM оценивает качество кода тестов.
