# Шаблон артефакта 3 — Unit-тесты на JUnit 5

> **Практика**: 3 (содержательная, 7 баллов)
> **Проверка**: CI-автопроверка (`java-services`)
> **Дедлайн**: конец недели 7

## Что сдаёте

Unit-тесты для целевых классов СМП (Gateway, Switch, Authorization, Card Management) на JUnit 5 + Mockito.

## Требования

- Покрыть бизнес-логику: assertions (не «просто не упало»), изоляция зависимостей (Mockito).
- Покрыть ветвления и границы (лимиты, статусы карт).
- Параметризованные тесты для классов эквивалентности.
- Тесты проходят в CI (`mvn test`).

## Куда класть

```
services/{service}/src/test/java/...
```

## Как сдавать

Ветка + Issue с label `practice-3`. CI проверяет сборку и прохождение тестов.
