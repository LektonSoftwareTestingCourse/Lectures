# FAQ для студентов

> Курс «Тестирование ПО», ИТМО, осень 2026.

## Где дедлайны?

Дедлайны по артефактам — в [`submission-guide.md`](https://github.com/LektonSoftwareTestingCourse/Practic/blob/main/docs/submission-guide.md) и в шапке каждой практики. Кратко:

| Практика | Дедлайн |
|:---:|---|
| 1 | конец недели 3 |
| 2 | конец недели 5 |
| 3 | конец недели 7 |
| 4 | конец недели 9 |
| 5 | конец недели 11 |
| 6 | конец недели 13 |
| 7 | конец недели 15 |
| 8 | конец недели 16 |

Все практики открыты с первого дня — можно сдавать досрочно.

## Как сдать работу?

1. Создать ветку `practice-{N}-{surname}` от `main`.
2. Выполнить задание, разместив артефакт по пути из таблицы в `submission-guide.md`.
3. Запушить ветку — CI проверит автоматически.
4. Создать Issue с заголовком «Практика N — Фамилия» и label `practice-N`, указать ссылку на ветку и путь к артефакту.
5. Для текстовых артефактов — вставить полное содержимое в тело Issue (для LLM-проверки).

## Какие порты у сервисов?

См. [`README.md`](https://github.com/LektonSoftwareTestingCourse/Practic/blob/main/README.md) — карта сервисов/портов. Ключевое: **Merchant Simulator = 8084** (не 8086).

## Что такое профиль `observability`?

Prometheus, Grafana, Loki, Promtail и autoscaler вынесены в отдельный compose-профиль. По умолчанию они **выключены**:

```bash
docker compose up -d                              # базовый набор (11 сервисов + PostgreSQL + RabbitMQ)
docker compose --profile observability up -d      # полный стек с мониторингом
```

Профиль понадобится в модуле 8 (метрики и нагрузочный smoke).

## Можно ли использовать LLM (ChatGPT, Claude, Copilot)?

Да. LLM разрешены как инструмент, но вы должны **понимать и уметь защитить** результат. На индивидуальной защите будут вопросы «почему тест устроен именно так». Не можете объяснить — работа не засчитывается.

## Что будет, если не успел к дедлайну?

Баллы снижаются, но артефакт всё равно засчитывается. Главное — довести работу до конца. Сдал в дедлайн — +5 бонусных баллов за практику.

## Как получить «Отлично»?

Только через индивидуальную защиту (+10 бонус). Без защиты максимум — «Хорошо», даже при 100% выполненных практик.
