# FAQ для студентов

> Курс «Тестирование ПО», ИТМО, осень 2026.

## Где дедлайны?

**Правило:** задание модуля N сдаётся до проходной **следующего** модуля (N+1). На проходной своего модуля — приёмка; если вернули на доработку, время до дедлайна есть. До дедлайна штрафа нет; после — баллы снижаются, но артефакт всё равно засчитывается.

| Модуль (практика) | Приёмка | **Дедлайн (дата сдачи)** |
|:---:|:---:|:---:|
| 1 | 11.09.2026 | **25.09.2026** |
| 2 | 25.09.2026 | **09.10.2026** |
| 3 | 09.10.2026 | **23.10.2026** |
| 4 | 23.10.2026 | **06.11.2026** |
| 5 | 06.11.2026 | **20.11.2026** |
| 6 | 20.11.2026 | **04.12.2026** |
| 7 | 04.12.2026 | **18.12.2026** |
| 8 | 18.12.2026 | **18.12.2026** (финал, модуля 9 нет) |

Полная версия и порядок сдачи — в [`submission-guide.md`](https://github.com/LektonSoftwareTestingCourse/Practic/blob/main/docs/submission-guide.md).

Все практики открыты с первого дня — можно сдавать досрочно.

## Как сдать работу?

1. Склонировать свой репозиторий `Practic{Имя}{Фамилия}` (его выдаёт куратор).
2. Выполнить задание, разместив артефакт по пути из таблицы в `submission-guide.md`.
3. Запушить ветку — CI в вашем репозитории проверит автоматически.
4. Создать Issue в эталонном репозитории `Practic` с заголовком «Практика N — Фамилия» и label `practice-N`, указать ссылку на свой репозиторий, ссылку на Actions run и путь к артефакту.
5. Для текстовых артефактов — вставить полное содержимое в тело Issue (для LLM-проверки).

## Что такое профиль `observability`?

Prometheus, Grafana, Loki, Promtail и autoscaler вынесены в отдельный compose-профиль. По умолчанию они **выключены**:

```bash
docker compose up -d                              # базовый набор (11 сервисов + PostgreSQL + RabbitMQ)
docker compose --profile observability up -d      # полный стек с мониторингом
```

Профиль понадобится в модуле 8 (метрики и нагрузочный smoke).

## Можно ли использовать LLM (ChatGPT, Claude, Copilot)?

Да. LLM разрешены как инструмент, но вы должны **понимать и уметь защитить** результат. На индивидуальной защите будут вопросы «почему тест устроен именно так». Не можете объяснить — работа не засчитывается.

## Что будет, если не успел к дедлайну?

Баллы снижаются, но артефакт всё равно засчитывается. Главное — довести работу до конца. За просрочку баллы за практику снижаются; фиксированных бонусов за срок нет.

## Как получить «Отлично»?

Только через индивидуальную защиту — это обязательный компонент сетки (10 баллов). Без защиты максимум — «Хорошо», даже при 100% выполненных практик.
