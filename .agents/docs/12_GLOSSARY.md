# Глоссарий

> Термины курса, репозитория и предметной области, встречающиеся в контенте.
> **Обновлять при:** появлении новых терминов и аббревиатур в лекциях и практиках.

## Обзор

Глоссарий фиксирует расшифровки, которые нужны для чтения контента без внешних
источников: организационные термины курса, обозначения учебного проекта СМП,
названия репозиториев и инструментов. Термины с расхождением в источниках
помечены ссылкой на `00_OPEN_QUESTIONS.md`.

## Детали

### Организация курса

| Термин | Значение |
|---|---|
| Силлабус | `COURSE_SYLLABUS.md` — параметры курса, модули, оценивание |
| РПД | Рабочая программа дисциплины; актуальная — `testing-course-internal/plans/РПД_Тестирование_ПО_ИТМО.md` (локальная копия в `materials/admin/`, untracked) |
| Артефакт | Оцениваемая работа студента; всего 8, шаблоны 1–7 в `materials/artifacts/` |
| Содержательная практика | Воркшоп с оцениваемым артефактом; 8 штук на семестр |
| Проходная практика | Слот для сдачи, приёмки и консультаций; отдельных баллов не даёт |
| БАРС | Балльно-рейтинговая система; модель курса 40 + 50 + 10 |
| Индивидуальная защита | Обязательный компонент на 10 баллов; без неё максимум «Хорошо» |
| Peer review | Взаимная проверка текстовых артефактов студентами |
| LLM-рубрика, skill-N | Автоматическая проверка не-кодовых артефактов в `testing-course-internal` |
| Quality gate | Порог качества в CI, блокирующий приёмку при невыполнении |
| ИТМО | Университет, для которого читается курс; 4 курс, дистанционно |
| Lekton | Компания-разработчик ПО для процессинговых центров; ведёт курс |

### Учебный проект СМП

| Термин | Значение |
|---|---|
| СМП | Учебный проект курса. В лекциях — «Симулятор процессингового центра»; в skill-1 — «Система межбанковского процессинга» (расхождение, Q-17) |
| Процессинг | Обработка банковских карточных транзакций |
| Gateway | Сервис СМП — точка входа для запросов |
| Switch | Сервис СМП — маршрутизация транзакций |
| Authorization | Сервис СМП — авторизация транзакций |
| Card Management | Сервис СМП — управление картами |
| Transaction Logger | Сервис СМП — журналирование транзакций |
| Merchant Simulator | Симулятор мерчанта; порт 8084, не 8086 |
| Terminal Simulator | Симулятор терминала |
| Профиль observability | Отдельный compose-профиль с Prometheus, Grafana, Loki, Promtail, autoscaler; по умолчанию выключен |
| Smoke-тест | Быстрая проверка работоспособности развёрнутой системы |

| GitHub Actions | CI/CD; пайплайны в `.github/workflows` |

| AAA | Паттерн Arrange–Act–Assert |
| OpenAPI | Контракт API; источник для контрактного тестирования |

| Quality gate | См. выше |
