# Структура курса и конвенции контента

> Карта модулей, практик, артефактов и правила оформления Markdown-файлов.
> **Обновлять при изменении:** `materials/`, `COURSE_SYLLABUS.md`

## Обзор

Курс состоит из 8 модулей по 2 лекции, 8 содержательных практик и 8 проходных
слотов. Контент модулей лежит в `materials/module-NN-*`, шаблоны заданий —
в `materials/artifacts/`, административные документы — в `materials/admin/`.
Ниже — соответствие модулей глобальной нумерации, карта практик и артефактов,
а также конвенции оформления, которым фактически следуют файлы.

### Конвенция файла лекции

| Элемент | Правило | Пример |
|---|---|---|
| Заголовок | `# Lecture N: Тема` | `# Lecture 1: Введение в тестирование и enterprise-системы` |
| Метаданные | Блок-цитата: Модуль, Лектор, Длительность, Слайдов, Формат, Структура слайда, Дата | Первые 10 строк файла |
| Доп. поля | `Связь с лекцией N`, `Литература` | `lecture-02.md` |
| Тайминг | Таблица `Время · Блок · Слайды · Назначение` | `module-01-intro/slides/lecture-01.md` |
| Разделители | `---` перед каждым слайдом | Все лекции |
| Слайд | `### Слайд N. Название` | Нумерация сквозная внутри лекции |
| Тело слайда | `**Слайд:**` + 3–5 буллетов | Опорные точки, а не полный текст |
| Заметки | `**Speaker notes:**` + цитаты `>` | Основная глубина и цитаты |
| Интерактив | `[ИНТЕРАКТИВ — N мин]` внутри заметок | Опросы аудитории |
| Источники | `## Источники` в конце, нумерованный список | Spillner, Bach & Bolton, ISTQB |
| Заметка лектору | Финальная цитата `> **Для лектора**: ...` | Тайминг и акценты |

Количество слайдов: 15 в большинстве лекций, 16 в `module-05/lecture-09.md`.
Метаданное «Слайдов» соответствует фактическому числу разделов `### Слайд`.

### Конвенция файла практики

| Элемент | Правило |
|---|---|
| Заголовок | `# Practice N: «Название»` |
| Метаданные | Модуль, Тип, Артефакт, Проверка, Длительность, Формат, Дата, Связь с лекциями, Дедлайн артефакта |
| Тип | «Содержательная практика» или «Проходная практика» |
| Связь с артефактом | Указывается номер и баллы артефакта |
| Связь с лекциями | Относительные ссылки на `../slides/lecture-*.md` |
| Внешние ссылки | Абсолютные ссылки на GitHub `Practic` (`submission-guide.md`, `git-workflow.md`) |
| Хвост файла | Блок полезных ссылок |

### Конвенция шаблона артефакта

| Элемент | Правило |
|---|---|
| Заголовок | `# Шаблон артефакта N — Название` |
| Метаданные | Практика (номер, баллы), Проверка, Дедлайн |
| Разделы | «Что сдаёте», «Требования» / «Структура артефакта», чек-лист приёмки |
| Ссылки | Пути сдачи вида `docs/practice-N/...` внутри репозитория студента |

### Конвенции именования

| Объект | Шаблон | Пример |
|---|---|---|
| Каталог модуля | `module-NN-english-topic` | `module-04-unit-tests` |
| Файл лекции | `lecture-NN.md` (нумерация **локальная, с `01` внутри модуля**) | `lecture-01.md` |
| Файл практики | `practice-NN.md` (нумерация **локальная, с `01` внутри модуля**) | `practice-01.md` |
| Шаблон артефакта | `artifact-N-topic.md` (глобальный номер = номер модуля) | `artifact-1-smoke.md` |
| PDF | `<имя лекции>.pdf` | `lecture-01.pdf` |
| Служебный пустой каталог | `.gitkeep` | `practice/.gitkeep` |
| Язык имён каталогов | английский | исключение — РПД-файлы на русском |
