# Конфигурация

> Конфигурация контент-репозитория: git-настройки, игнорируемые файлы, внешние
> сервисы. Переменных окружения, конфиг-файлов и секретов нет.
> **Обновлять при изменении:** `.gitignore`

## Обзор

`Lectures` не исполняется, поэтому классической конфигурации (env-переменные,
профили, файлы настроек) в нём нет. Единственные конфигурационные артефакты —
`.gitignore` и настройки git-репозитория. Внешние зависимости носят
организационный характер: GitHub как хостинг и системы ИТМО для сдачи РПД.
Секретов в репозитории нет; `.env` отсутствует (проверено только наличие файла).

## Детали

### Переменные окружения

Отсутствуют. В репозитории нет `.env`, `.env.example`, шаблонов переменных и
конфигов, которые их читают. Контент описывает `.env` учебного проекта СМП, но
сам файл и его шаблон живут в репозитории `Practic`, а не здесь.

### Конфигурационные файлы

| Файл | Назначение | Правила |
|---|---|---|
| `.gitignore` | Исключения для git | См. таблицу ниже |
| `.idea/*` | Локальные настройки IntelliJ IDEA | Присутствуют локально, но игнорируются git-ом |
| `.gitkeep` | Удержание пустых каталогов | Не конфигурация в строгом смысле; соглашение репозитория |

Содержимое `.gitignore`:

| Правило | Что исключает |
|---|---|
| `~$*.pptx`, `~$*.docx`, `~$*.xlsx` | Lock-файлы Office |
| `Thumbs.db`, `.DS_Store` | Служебные файлы ОС |
| `*.tmp` | Временные файлы |
| `.idea/` | Каталог IDE |

> Примечание: PDF и JPEG **не** игнорируются — экспортированные материалы
> коммитятся как бинарные файлы рядом с исходниками.

### Git-конфигурация

| Параметр | Значение |
|---|---|
| Текущая ветка | `main` |
| Remote | `origin` → `https://github.com/LektonSoftwareTestingCourse/Lectures.git` |
| Стратегия веток | Работа в `main`; отдельных веток/PR-процесса в истории не видно |
| Стиль коммитов | Conventional Commits: `feat`, `fix`, `docs`, `chore` |
| Теги/релизы | Отсутствуют |
| Submodules | Отсутствуют |
| LFS | Не используется; PDF закоммичены напрямую |

### Внешние сервисы

| Сервис | Роль | Где проявляется |
|---|---|---|
| GitHub `LektonSoftwareTestingCourse` | Хостинг репозитория, Issues, Actions | Remote, ссылки из лекций |
| GitHub `Practic` | Эталонный проект СМП, приёмка, CI | Внешние ссылки в лекциях и практиках |
| GitHub Issues | Сдача практик с label `practice-N` | Описано в `faq-students.md`, `practice-*.md` |
| GitHub Actions | CI в репозитории студента и в `Practic` | Описано в контенте, в этом репо не настроен |
| Внутренняя система ИТМО | Заполнение официальной формы РПД | `materials/admin/РПД_Тестирование_ПО_ИТМО.md` (локальная копия, untracked); актуальная — `testing-course-internal/plans/РПД_Тестирование_ПО_ИТМО.md` |
| LLM-рубрики `testing-course-internal` | Проверка текстовых артефактов | Упоминаются в лекциях и шаблонах |

### Feature flags

Отсутствуют. «Переключатели» курса носят содержательный характер и задаются
текстом: модель оценивания 40+50+10, политика LLM, набор содержательных и
проходных практик.

### Секреты

| Что | Статус |
|---|---|
| Пароли, токены, ключи | Не обнаружены в отслеживаемых файлах |
| `.env` | Отсутствует (проверено наличие; содержимое не читалось) |
| Приватные ссылки | Не обнаружены; внешние ссылки ведут на публичные GitHub-репозитории |
